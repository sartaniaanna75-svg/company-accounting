# Как пользоваться WorkTime

## Вход

Откройте [index.html](../index.html), затем **«Открыть табель»**. Выберите отдел и введите PIN. Enter тоже отправляет форму.

## Отдел (магазин, офис, склад, водители)

1. **ФИО сотрудника** — добавьте человека в список **этого** отдела. Другие отделы его не видят.
2. **Табель месяца** — в первой графе выберите сотрудника из списка. Отметьте дни: Я, О, Б, ОТ, В.
3. **В табель** — тот же подбор списком, если удобнее отметить сразу нескольких.
4. **Дисциплина** — сводка опозданий за выбранный месяц.
5. Месяц переключается закладками под шапкой.

Кнопка «Заполнить месяц» ставит явки на будни и выходные на сб/вс, уже заполненные дни не трогает.

## Общая таблица

Сюда ничего не заводят вручную. Кто выбран в табеле отдела, появляется сам.

- **Сводка** — часы и явки по всем отделам.
- **Зарплата** — штрафы, премии, авансы, продукты.
- **Анализ** — сравнение соседних месяцев.

## Резервная копия

Настройки → скачать JSON. Загрузка копии заменяет все таблицы после подтверждения.
