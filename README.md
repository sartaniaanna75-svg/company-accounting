# WorkTime — учёт рабочего времени

Локальный сайт для табеля сотрудников: четыре отдела (магазин, офис, склад, водители) и общая сводка по зарплате.

Данные хранятся в браузере (`localStorage`). Сервер не нужен.

## Как открыть

1. Скачайте или клонируйте этот репозиторий.
2. Откройте `index.html` в браузере (двойной щелчок или «Open with Live Server»).
3. Нажмите **«Открыть табель»** / **«Начать работу»**.
4. Войдите в отдел по PIN-коду.

Стандартные PIN (их можно сменить в настройках):

| Таблица   | PIN  |
|-----------|------|
| Магазин   | 1111 |
| Офис      | 2222 |
| Склад     | 3333 |
| Водители  | 4444 |
| Общая     | 5555 |

## Что внутри

- **ФИО сотрудника** — список только этого отдела: имя, должность, ставка, график.
- **Табель** — подбор сотрудника в графе «Сотрудник», статусы дня (Я / О / Б / ОТ / В), часы и минуты опоздания.
- **Дисциплина** — явки, опоздания, оценка за месяц.
- **Общая** — сводка по всем отделам, зарплата, анализ по месяцам.
- **Резервная копия** — JSON и выгрузка CSV.

Формула выплаты:

`часы × ставка − удержание за опоздание − штрафы + премии − авансы`

Сумма продуктов учитывается отдельно. Сотрудники в отделах не пересекаются: каждого заводят в своей таблице.

## Структура репозитория

```
index.html                      приветственный лендинг
app.html                        рабочее приложение
css/landing.css                 стили лендинга
docs/usage.md                   краткая инструкция
Учет рабочего времени.html      переход на лендинг (старый ярлык)
```

## Сохранение данных

- Табели пишутся в `localStorage` ключом `worktime_three_tables_v1`.
- Сделайте резервную копию JSON в настройках, если чистите историю браузера.
- Обновление страницы не сбрасывает вход в текущей вкладке.
